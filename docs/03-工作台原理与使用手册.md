> 配套对象：本地运行在 `http://localhost:8503` 的 Streamlit 工作台（GitHub 私人仓库 cross-border-analysis，已部署的公开 demo 见作品集门户）。

## 0. 先讲清楚这个工作台是什么

它不是一个"好看的数据大屏"，是把 B1 项目里那个问题接着往下做成的 4 个能算账的小工具。问题是你上一份工作里真实遇到的：**单品怎么算都赚钱，公司整体却不比以前**。B1 用 5 家上市公司的财报把"钱被谁赚走了"从行业层面验证了一遍；这个工作台则是把验证得到的结论，变成你（或任何一个想做跨境电商的人）在四个决策点上能直接填数字、看结果的账本。

四个模块各回答一个问题：

| 模块 | 回答的问题 | 什么时候用 |
|---|---|---|
| P1 单位经济测算 | 这件货散卖 vs 整箱卖，到底哪个赚 | 给新品定价、要不要上 Case Pack 之前 |
| P2 选品类助手 | 这个品类能不能做、风险大不大 | 想开一个新品类、拿不准要不要铺量 |
| P3 市场选择器 | 美国/欧洲/日本/东南亚先做哪个 | 手里资源有限，要决定主战场 |
| P4 经营健康体检 | 我现在算不算健康、要不要转型 | 每季度给自己（或假设的公司）做体检 |

每个模块都能独立用。它们之间有一个自然的先后顺序：先 P1 确认单件能赚 → 再 P2 决定要不要做这个品类 → P3 决定在哪个市场卖 → 经营一段时间后用 P4 检查有没有跑偏。下面按这个顺序讲。

## 1. 两个绕口的名词：归母净利、OCF（P4 会用到，先讲）

这两个词都来自上市公司财报，你在 P4 要亲手输入"OCF/归母净利"这个比值，所以先把它们讲透。

### 归母净利润（归母净利）
利润表最下面那一行里，属于**母公司股东**的那部分利润。
一家上市公司下面常有很多子公司，子公司里可能还有别的股东（少数股东）。合并报表算出来的总净利润，要扣掉分给少数股东的部分，剩下的才是"归母净利润"。散户和机构看一家公司赚多少钱，默认看的都是这一行。

在项目数据里，安克创新 2025 年归母净利是 **25.45 亿元**（数据表 `归母净利润` 字段）。

### OCF（经营性现金流 / 经营活动现金流量净额）
现金流量表里"经营活动"产生的**实际现金流入减流出**。
利润表是按权责发生制记账的：货发出去了、发票开了，就记为收入，哪怕钱还没到账；采购入库了，哪怕还没付款，也可能记为成本。所以利润表上的"赚"，不一定是真金白银进了账户。
OCF 回答的是另一个问题：**这一年，做生意真正收进来、付出去多少现金**。

在项目数据里，安克 2025 年经营现金流量净额是 **4.81 亿元**。

### 为什么要看 OCF/归母净利 这个比值
把两者放一起，衡量的是：**账面上的利润，有多少真的变成了现金**。

- 比值 ≈ 1：赚的钱基本都收回来了，比较健康。
- 比值 > 1：经营现金流比净利润还多。可能因为折旧摊销这类非现金成本大、也可能因为预收货款多、存货周转快把现金释放出来了。本身不算坏事，但要结合看是不是一次性因素。
- 比值 < 1（尤其长期 < 0.5）：利润被压在**存货和应收账款**里。跨境电商特别典型——货先备到海外仓，钱花出去了，货要慢慢卖、卖了还要等回款，账上显示盈利，手里却越来越紧。

P4 里默认给了一个危险阈值：**OCF/归母净利 < 0.3 触发"现金流警报"**。这个阈值不是拍脑袋，是看样本来的：安克 2025 年这个比值只有 0.19，属于"利润没怎么变成现金"的典型，工具就把它标成警讯。样本里也有反例：致欧科技 2025 年 OCF 24.7 亿、归母净利 3.36 亿，比值约 7.4，说明它利润虽薄但现金流很厚——这就是"活得下去"和"账面上活得好"的区别。

**一句话记法**：净利率高不一定安全，OCF/净利 高才说明手里有钱；现金流才是小公司的命。

## 2. P1 单位经济测算（含 Case Pack 整箱对比）

### 2.1 这一页解决什么
定价和上架前最该问的问题：**单价卖多少、广告花多少，这件货才不亏？** 以及第二个问题（你上一份工作的核心场景）：**同一个 SKU，散着卖和整箱卖，哪个 ROI 高？**

页面分两个 tab：

### 2.2 Tab 1「单方案测算」：单件账
**填什么**（都是单件口径）：
- 售价（美元）、采购成本（美元）、头程+入库（美元）、其他分摊（美元/件，如仓储、退货）
- 平台佣金率：下拉选品类。注意这里默认是**工业品 & 科研用品 12%**，因为你上一份的阀门/管件/实验室器材属于 Business, Industrial & Scientific Supplies，官方佣金率就是 12%，不是大众印象里的 15%。
- FBA 配送费：这一页不填尺寸，所以用"按体积重量近似"的档位估，或直接自定义
- 广告 ACOS %：广告花费 ÷ 销售额，滑杆从 0 到 80

**公式**（代码里 `calc()` 函数，全部按单件）：
```
佣金    = 售价 × 佣金率
广告    = 售价 × ACOS
总成本  = 采购成本 + 头程/其他
净利    = 售价 − 总成本 − 佣金 − FBA − 广告
净利率  = 净利 ÷ 售价
盈亏平衡ACOS = (售价 − 总成本 − 佣金 − FBA) ÷ 售价
```
**怎么读**：
- 单位净利那栏如果小于 0，说明这价格连平台费和成本都盖不住。
- "盈亏平衡 ACOS" 是最有用的一栏：只要广告 ACOS 低于这个数，这单就还有钱赚；高于它就开始亏。比如下面例子算出来是 33%，意味着广告占比超过 33% 就不要投了。
- 旁边那张"单位净利 vs 广告 ACOS"曲线，就是直观给你看：ACOS 每涨一点，净利往下跌多少，跌到 0 的位置就是盈亏平衡点。
- "平台+广告占售价"那栏能回答你当年那个困惑的一半：**钱被谁赚走了**——佣金、FBA、广告三项加起来经常吃掉售价的三四成，这部分是平台拿走的。

### 2.3 Tab 2「双方案对比」：散卖 vs Case Pack 整箱
这是这一页最值钱的部分，直接复刻你当时的决策：**把 10 个阀门装成一箱，整箱价格打个折卖给要批量采购的客户（工程师、实验室、做自动化改造的公司），ROI 反而更高吗？**

**填什么**：
- 单件采购成本（**人民币**）、单件售价（**美元**）、每箱件数、汇率
- 品类佣金率（下拉，同上）；是否勾选批量销售佣金折扣（Amazon Bulk Services，下面讲）；FBA 价档（<$10 / $10–50 / >$50）
- 整箱售价调整：整箱再打折（滑杆，默认 20 就是打 8 折）、取整方式（不取整 / 取整到整数美元 / 取整到 .99）
- 尺寸重量，两组：**单件**的长宽高(in)和重量(lb)，**整箱**的长宽高(in)和重量(lb)

**工具自动做的事**：
1. **整箱总售价** = 单件售价 × 件数 × (1 − 折扣)，再按你选的取整方式处理；**整箱总成本** = 单件采购成本(¥) × 件数。这两个数会自动算好显示在结果卡里。
2. **算 FBA 配送费**：先算计费重量 = max(实际重量, 长×宽×高÷139)。139 是体积重折算系数（英寸制，1 立方英尺约 1728 立方英寸 ÷ 12.4 ≈ 139，物流行业通用做法），然后按尺寸自动判断档位：
   - 小号标准：最长边 ≤15in、次长 ≤12in、最短 ≤0.75in 且 ≤1lb
   - 大号标准：≤18×14×8in 且 ≤20lb
   - 超出就算"超规/大件"，工具会提示你**用亚马逊官方 FBA Revenue Calculator 精算**，不硬编一个数骗你
   - 落在档内就查 2026 美国站非旺季 $10–50 主表；超过 3 磅每多 4oz 加 $0.08（官方口径是 3 磅以上每半磅 +$0.16，等价）
3. **佣金** = 整箱总售价 × 类目佣金率。勾了批量折扣且箱子**满足官方条件**，就再乘 (1 − 折扣率)。
4. **广告** = 整箱总售价 × 15%（按你说的先固定 15%，不摊 ACOS）。
5. **算 ROI**，输出两个对比：散卖单件 ROI vs Case Pack 整箱 ROI。

**Amazon Bulk Services（批量佣金折扣）到底是怎么回事**——这是你当年看到的那个政策，官方口径如下（来源见文末）：
- 同一产品做成 package hierarchy（单件/整箱/托盘 的层级）并在美国站、专业销售计划、品牌注册授权方名下，可享受佣金折扣：
  - 2–9 件：佣金减 15%
  - 10–23 件：减 20%
  - 24 件及以上：减 25%
- **不是所有箱子都自动够格**。官方要求整箱售价 > $20，且至少满足一条：件数 ≥10，或体积 ≥1400 立方英寸，或重量 ≥35 磅。
- 我在这轮给工具加了**资格自动校验**：工具会用你填的整箱尺寸、重量、件数和折后总价自动判断够不够格；不够格就不打折，并在页面上明确提示原因。这样你拿去面试也能说："我连政策边界都做了校验，不是无脑套 25%。"

**完整走一遍你的真实例子**（阀门这类工业品，就用工具当前默认值）：
```
单件售价 $25，采购成本 ¥60，每箱 10 件，汇率 7.2
品类：工业品 & 科研用品 12%，勾选批量折扣（10 件 → 减 20%）
整箱打 8 折（-20%），FBA 价档 $10–50
单件尺寸 8×6×4 in / 1.2 lb；整箱 12×10×8 in / 13 lb
```
计算结果：

| 项目 | 散卖（每件） | Case Pack（整箱 10 件） |
|---|---|---|
| 售价 | $25.00 | $200.00（10 件 × $20，8 折后） |
| 平台佣金 | $3.00（12%） | $19.20（12% 再减 20% = 9.6%） |
| FBA 配送费 | $5.42 | $10.17（整箱只收一次） |
| 广告 15% | $3.75 | $30.00 |
| 净利 | $12.83 | $140.63（每件 $14.06） |
| 折人民币净利 | ¥32.38 | ¥412.54 |
| **ROI** | **54.0%** | **68.8%** |

**为什么整箱打 8 折反而更赚？** 两个原因，都在拆解表里看得到：
1. **FBA 省得最多**。散卖 10 件 = 10 个包裹，每件 $5.42，合计 $54.2；整箱是一个包裹 $10.17，省了约 $44。
2. **佣金打折**。整箱佣金从 12% 降到 9.6%，再省一笔。
广告虽然按整箱总价也算了一笔，但整箱总价因为打折反而比 10×单件原价低，所以广告没多花。这就是你当年那个直觉的数学证明：**单件价格打了折，但履约和佣金省下来的钱，比打折让掉的更多。**

> 提醒：FBA 数值是 2026 非旺季、$10–50 价档、不含 4/17/2026 起 3.5% 燃油附加费的口径；每个品类在卖家后台的真实归属可能和下拉标签不同，所以页面底部和本文都写了同一句：**落地前用亚马逊官方 FBA Revenue Calculator 复核**。

## 3. P2 选品类助手

### 3.1 这一页解决什么
你以前会为新品做选品调研。这一页把"能不能做"拆成两部分：**账上能不能赚**（单位经济） + **风险多不多**（6 个勾选项），最后给一句该不该做的判断。适合的场景：看到一个新品类（比如从阀门延伸到封口机、研磨仪），先别急着开模备货，花两分钟算一算。

### 3.2 怎么用
左侧填单件账（预期售价、采购+头程到仓、佣金、FBA 档位、假设 ACOS），右侧勾风险：
- 高退货（服装鞋码这种尺寸敏感的）
- 大件/超重（运费仓储贵）
- 带电/易碎/需认证（合规周期长）
- 强季节性（一年只卖几个月，现金流波动大）
- 强品牌垄断/大牌低价品
- **你能做出差异**（规格/材质/组合/私模）——这一项是反着勾的，不勾就等于"谁都能卖"，工具会直接警告你注定打价格战

### 3.3 结果怎么读
先看单位经济三张卡：净利、净利率、盈亏平衡 ACOS（公式同 P1）。然后看信号灯：
- 净利 ≤ 0 → 红：单位经济不成立，先改定价或降成本，别铺量
- 净利率 < 5% → 橙：勉强能做，抗风险弱
- 风险命中 ≥3 项 → 红：建议换方向或先小批量验证
- 命中 1–2 项 → 展开看逐条对策

**边界（页面里也写了）**：这页只能判断"成本/费率结构上能不能做"，判断不了需求热度、Top100 集中度、review 分布——那些要卖家后台或选品工具补数据。面试时主动讲这条边界，比硬说"我全都能判断"可信得多。

## 4. P3 市场选择器

### 4.1 这一页解决什么
美国、欧洲、日本、东南亚，先做哪个。对刚起步的小公司，同时铺几个市场基本等于找死，这页逼你先选一个主战场。

### 4.2 打分逻辑
六个维度，每个市场都有 1–5 的原始分，你给每个维度设权重（0–5），最后 `加权得分 = Σ 维度分 × 权重`，排序取最高。
注意口径：**规模 / 毛利 / 增长 分越高越有利；竞争压力 / 本地化难度 / 资金需求 分越高越不利**。三个负向维度目前是按原始分直接相加的，所以这页适合拿来排"方向"，别当精确分数（页面"局限"里也写了）。
各市场的一句话依据都写在数据表旁边，比如：
- 美国：出口占比最大、基础设施最成熟，但最卷（规模基本盘）
- 欧洲：致欧证明能赚毛利（欧洲毛利率 36% 高过美加 30%），但要啃认证、多语言
- 日本：客单价高、退货低，语言门槛高
- 东南亚：增速快、门槛低，但客单价低、基建不成熟（赌增长）

### 4.3 怎么用
默认所有维度权重 = 3 时先跑一遍看排序，这相当于"没有偏好"的基准答案；再按你的实际情况调权重跑第二遍。两次结论一致，说明这个选择比较稳；结论翻来覆去变，说明几个市场本来就接近，需要你自己拍板。

调权重的原则就一条：权重代表你**有多在意这个维度**。注意三个负向维度（竞争压力、本地化难度、资金需求）目前是原始分直接相加的，分越高反而越不利，所以不建议给它们设过高的权重——那会把"更难的市场"顶上去，和直觉相反。真要表达"我很在意资金门槛"，更稳妥的做法是把正向往的维度（规模、毛利、增长）里你真正看重的那个权重调高，让"又好做又满足你偏好"的市场浮上来。

## 5. P4 经营健康体检

### 5.1 这一页解决什么
这是整个工作台和 B1 结论咬得最紧的一页。B1 用 5 家上市公司（安克创新、致欧科技、赛维时代、华凯易佰、吉宏股份）2025 年报算出了行业的"正常区间"，这一页让你把自己（或你假设的公司）的指标填进去，看你在不在这个区间、像谁、有没有危险信号。

### 5.2 输入什么
- 毛利率 %、销售费用率 %、净利率 %、营收同比增速 %（利润表口径）
- OCF/归母净利（就是第 1 节讲的那个比值，比如 0.5）
- 存货周转率（次/年）
- 营收规模阶段：验证期 <100 万 / 复制期 100 万–1000 万 / 放大期 1000 万–1 亿 / 升级期 >1 亿
- 模式：品牌精品 / 泛品铺货 / 长尾全品类品牌 / 平台+独立站混合

### 5.3 输出什么
1. **你和 5 家中位数的对比表**：每项标 ▲高于基准 / ▼低于基准 / ≈持平。
2. **最像谁**：用欧氏距离（先对每个指标做归一化，再算你和 5 家公司的距离，取最近）告诉你财务结构最接近哪家——只代表结构近似，不代表水平相同。
3. **危险信号**（每条都给了为什么和怎么办）：
   - 净利率 < 2%：盈利警报，增收不增利（样本里华凯易佰 1.6% 同区）
   - 销售费用率 > 35%：平台税过重，你在给平台和流量打工（接近赛维/吉宏）
   - OCF/归母净利 < 0.3：现金流警报，利润被存货占住（安克 0.19 就是警讯）
   - 增速 < 5%：增长停滞，旧打法见顶，要找第二曲线
   - 毛利率 < 35%：毛利偏低，产品缺差异化或成本无优势（低于致欧/华凯）
4. **阶段建议**：按你选的规模给一句该阶段该干嘛，并提醒"如果同时触发盈利和现金流警报，先回到单位经济为正 + 现金流为正，再谈规模"。

**基准怎么来的（边界）**：5 家公司 2025 年报（B1 M3 计算），危险阈值是按样本分布划的参考线，不是铁律；上市公司有幸存者偏差，小公司费用结构可能差更多。工具建议你**每季度体检、看趋势而不是单点**——这也正好是 B1 里"转型信号"的落地：连续两个季度 OCF/净利走低、毛利率下滑，就该收着点，别扩张。
