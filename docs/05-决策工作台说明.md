# 决策工作台设计与口径说明

这套多页工作台（Streamlit）是把项目结论落成"能算账、能决策"的工具，围绕四个问题各做一页。在线体验：https://cross-border-analysis.streamlit.app/

仓库内运行：

```bash
pip install -r streamlit_app/requirements.txt
streamlit run streamlit_app/app.py
```

设计原则：能给出基准、可行性、风险信号与转型阈值；需要私有数据的地方（需求热度、供应商报价）明确提示"要补什么"，不假装能算。

## P1 单位经济测算（这件货赚不赚钱）

- **单方案测算**：输入单件售价、采购成本、头程+入库、仓储/退货分摊、类目佣金率、FBA、广告 ACOS。
  口径：
  - 佣金 = 售价 × 类目佣金率；广告 = 售价 × ACOS；
  - 净利 = 售价 −（采购成本 + 头程 + 分摊）− 佣金 − FBA − 广告；
  - 盈亏平衡 ACOS =（售价 − 总成本 − 佣金 − FBA）/ 售价，即广告占比超过该值开始亏损。
- **双方案对比（Case Pack）**：同一 SKU 散卖 vs 整箱。输入单件成本（人民币）/售价（美元）、每箱件数、整箱折扣与取整、单件与整箱的尺寸重量。
  工具自动完成：
  1. 整箱总售价 = 单件售价 × 件数 ×（1 − 折扣），可再取整；整箱总成本 = 单件成本 × 件数；
  2. 计费重量 = max(实际重量, 长×宽×高 ÷ 139)，按尺寸自动判断小号标准 / 大号标准 / 超规（超规提示用官方计算器精算）；
  3. FBA 费查 2026 美国站非旺季 $10–50 主表，3 磅以上每多 4oz +$0.08；
  4. 佣金按类目费率；若满足 Amazon Bulk Services 官方条件则自动叠加批量折扣（2–9 件 −15%、10–23 件 −20%、24 件+ −25%），不满足不打折并提示原因；
  5. 广告按整箱售价 15% 计；
  6. 输出散卖单件 ROI vs 整箱 ROI 与费用拆解。

  我做的校验：批量折扣不是无脑套——官方要求整箱售价 >$20 且（件数≥10 或 体积≥1400 in³ 或 重量≥35 lb），工具用输入的整箱尺寸实时判断是否达标。

## P2 选品类助手（这个品类能不能做）

输入单件账（售价/成本/佣金/FBA/假设 ACOS）+ 勾选风险特征（高退货、大件超重、带电认证、强季节、品牌垄断、能否做差异）。输出单位经济三卡（净利、净利率、盈亏平衡 ACOS）与红黄绿判定：净利 ≤0 或净利率 <5% 或命中风险过多时给出"别铺量/先小批量验证"的动作建议。页面同时列出上线前必须补的私有数据。

## P3 市场选择器（先做哪个市场）

对美国/欧洲/日本/东南亚在六个维度（规模、毛利、增长、竞争压力、本地化难度、资金需求）打 1–5 分并让用户调权重，输出加权排序。口径上明确：规模/毛利/增长分数越高越有利；竞争/本地化/资金分数越高越不利，因此本页用于"排序方向"，不当精确分数。每个市场附一句话依据与局限说明。

## P4 经营健康体检（我现在健康吗、该转型吗）

输入毛利率、销售费用率、净利率、营收增速、OCF/归母净利、存货周转、营收规模阶段与模式，对标 5 家上市公司 2025 基准（中位数）：
- 输出与基准的逐项对比表 + 财务结构最接近哪家公司（归一化欧氏距离）；
- 危险信号：净利率 <2%（盈利警报）、销售费用率 >35%（平台税过重）、OCF/净利 <0.3（现金流警报）、增速 <5%（增长停滞）、毛利率 <35%（毛利偏低）；
- 按规模阶段给出建议，并提示"同时触发盈利与现金流警报时，先回到单位经济为正 + 现金流为正再谈规模"。

基准与阈值来自 5 家样本分布，是参考线而非铁律；建议每季度体检看趋势。

## 数据边界（工具内也标注）

- FBA 费率按 2026 非旺季、$10–50 价档、不含燃油附加费；品类归属以卖家后台为准，最终费用用官方 FBA Revenue Calculator 复核；
- 未含退货损失、仓储超期费、汇率波动与税务，属单件账的简化边界；
- P3 市场打分为公开数据+经验估计；P4 基准存在幸存者偏差。
