## 3. M3 公司对比：为什么"毛利率高 ≠ 赚钱"

### 3.1 计算前手里有什么
`annual_key_metrics.csv`（毛利率、净利率、存货周转率等摘要指标）+ `profit_sheet_annual.csv`（销售/研发费用明细，从利润表接口补的）。

`profit_sheet_annual.csv`（单位：元）：
```csv
公司名称,年份,营业收入,销售费用,研发费用
安克创新,2025,30514403376.92,6826802834.83,2892785453.80,...
```

### 3.2 每个指标怎么算 + 公式意义 + 高低代表什么
| 指标 | 公式 | 意义 | 高 | 低 |
|---|---|---|---|---|
| 营业收入同比% | (今年营收 − 去年营收) ÷ 去年营收 ×100 | 公司扩张速度 | 增长快（但要问质量） | 停滞/萎缩 |
| 毛利率% | 毛利 ÷ 营收 ×100 | 产品本身赚不赚钱（没扣销售/管理/研发费） | 产品有溢价或成本控制好 | 产品同质化/成本高 |
| 销售费用率% | 销售费用 ÷ 营收 ×100 | 卖货要花多少钱（含平台佣金+广告+推广） | **"流量税"重**，靠买量 | 品牌/复购强，获客便宜 |
| 归母净利率% | 归母净利 ÷ 营收 ×100 | 扣除一切后股东真正拿到多少 | 真赚钱 | 赚得薄/不赚钱 |
| 研发费用率% | 研发费用 ÷ 营收 ×100 | 在产品/技术上投入多少 | 品牌型公司高（安克 9.5%） | 铺货型 <1% |
| OCF/归母净利 | 经营现金流 ÷ 归母净利 | 利润有没有变成现金 | ≥1 说明利润实在 | <1 说明利润被货/应收占住 |
| 存货周转率 | 营业成本 ÷ 平均存货 | 货卖得多快 | 周转快、压货少 | 积压、占用资金 |

### 3.3 计算脚本存了结果
`scripts/m3_company_analysis.py` 把上面公式逐公司逐年生成了 **`data/consolidated/company_metrics_annual.csv`**（已落盘，单位：亿元/%）：

```csv
公司名称,年份,营业收入亿,营收同比%,毛利率%,归母净利率%,销售费用率%,研发费用率%,...
安克创新,2025,305.1,23.5,45.1,8.3,22.4,9.5,...
赛维时代,2025,118.2,15.0,42.7,2.4,35.4,0.9,...
```

> 你 PPT/报告里所有"安克 45.1%、22.4%、8.3%"都从这张表来，可以直接打开 CSV 核对。

### 3.4 图长什么样（中文）
![2023-2025 营收对比](b1-images/m3_revenue.png)
![2025 毛利率 vs 净利率](b1-images/m3_margin_2025.png)
![销售费用率趋势](b1-images/m3_sale_expense_rate.png)

### 3.5 从数字到结论（这页验证你 why 的猜测②）
- 安克：毛利 45.1%、销售费用率只有 22.4% → 净利率还能剩 **8.3%**；
- 赛维：毛利 42.7% 不低，但销售费用率 **35.4%** → 净利率只剩 **2.4%**；
- 华凯：净利率 1.6%、营收只 +1.2% = **增收不增利、增长见顶**。

**结论**：两家毛利都 40%+，差 4 倍净利率，中间差的**不是产品，是费用结构**。铺货型靠买量/测款 → "流量税"高；品牌型靠研发+复购把销售费用率压下来。**这就是"单品盈利≠整体赚钱"的机制**：铺货每个 SKU 毛利都正，但海量 SKU 分摊的广告费用太高，公司净利只剩 1~3%。

## 4. M3b 现金流：为什么"利润 ≠ 现金"

### 4.1 取数 + 存储
`scripts/m3b_anker_cashflow.py`（联网）拉安克现金流量表 + 资产负债表 → 存：
- `data/raw/anker_cashflow_annual.csv`、`data/raw/anker_balance_sheet_annual.csv`（原始）
- `data/consolidated/anker_cashflow_annual_整理.csv`（已换算成**亿元**、只留年报、含调节附表）
- `data/consolidated/anker_balance_sheet_annual_整理.csv`

`anker_cashflow_annual_整理.csv`（行=年报，列=项目）关键几列长这样：

```csv
,净利润,存货的减少(减:增加),经营性应收减少(减:增加),经营性应付增加,经营现金流净额(主表)
2023年报,16.94,-9.57,-3.69,10.16,14.3
2024年报,22.11,-8.05,-5.33,18.81,27.45
2025年报,26.17,-20.04,-6.61,2.12,4.81
```

### 4.2 核心公式：怎么从"净利润"推出"经营现金流"
现金流量表的**调节附表**（间接法）告诉你利润去哪了：

> 经营现金流 ≈ 净利润 ＋ 折旧摊销等非现金项 ＋(经营应付增加) −(存货增加) −(应收增加)

代入安克 2025：26.17 − 20.04(存货) − 6.61(应收) ＋ 2.12(应付) ＋ 其他 ≈ **4.81 亿** ✅
→ 结论：**钱被"存货 + 应收"占住了**，其中存货是大头（一年多备货约 20 亿）。

### 4.3 图长什么样（中文）
![安克现金流](b1-images/m3b_anker_cashflow.png)

**怎么读**：
- 2023、2024 净利润 ≈ 现金流（健康）；
- **2025 净利润 26.17 亿（归母 25.5 亿），经营现金流只有 4.81 亿，OCF/净利≈0.19**；
- 佐证：资产负债表存货余额 24.1 → 32.3 → **50.0 亿**（一年 +17.6 亿），和调节表 −20 亿同向互相印证。

**高/低代表什么**：OCF/净利 ≥1 = 利润是"真金白银"；<1 = 利润只是"账面数"，变成了货和应收。跨境电商要提前备货、回款有账期，**现金流才是生死线**——这直接回答你 why 的猜测④，也和你当年压美国仓库存、算 Case Pack 的体感同源。
