# 中国跨境电商 / 出海赛道分析 · 项目方案书

作者：Xuefei Wang · 2026 · 数据分析 / 商业分析 / 产品方向

## 一句话定位

用 5 家 A 股跨境电商上市公司的公开财报 + 海关官方统计，回答"跨境电商公司怎么赚钱、怎么才能走得长远"——把行业、模式、市场渠道、资金四条线拆开，得到可核验的结论，再把结论做成能用的决策工具。

## 1. 背景：这个问题为什么长在我身上

我上一份工作在一家做自有品牌出海的公司做亚马逊运营，卖阀门/管件、实验室仪器、封口机这类偏专业的产品，在售 SKU 超过 1000 个。经营上我们按品类做深做全：同一类阀门按通径、材质和螺纹标准展开，两通/三通、1/2 到 2 英寸、不锈钢/黄铜/PVC 都会配齐，买家多是工程师、实验室或做自动化改造的人，下单前会核对型号参数。

我负责日常运营，也参与新品选品：给新品定价前先算单件 ROI，再决定广告投入和备货节奏。一线做得越久，我越想知道一个更大的问题——**跨境电商公司到底怎么赚钱、怎么才能走得长远**：平台佣金、仓储、广告和备货库存，如何影响一家公司的利润与现金流？

我决定不套用现成数据集，用上市公司财报 + 海关官方数据自己验证一遍。

## 2. 我把研究问题拆成四个可量化的问题

1. **行业**：这盘生意还有多大、还在涨吗？为什么门槛低、进来多、倒得也快？
2. **模式**：精品 / 铺货 / 长尾，谁的利润更能留下来？
3. **市场与渠道**：北美 vs 欧洲、平台 vs 独立站，如何影响毛利与费用？
4. **经营与资金**：为什么利润和现金流经常对不上？现金流是不是生死线、如何判断该转型？

## 5. 分析框架：三层漏斗

```
第 0 层 数据底座：5 家财务 + 宏观 → 统一口径宽表 + 数据字典（含每列口径）
        ↓
第 1 层 宏观（行业）：规模/增速/进出 → 这个行业还值不值得进、增长来自哪
        ↓
第 2 层 中观（公司对比，核心）：
        ├─ 规模与增长：营收、营收增速、归母净利增速
        ├─ 盈利质量：毛利率、净利率、销售费用率、OCF/净利
        ├─ 运营效率：存货周转、存货/营收
        ├─ 结构：分地区/分品类/渠道占比
        └─ 结论：模式/市场/渠道三维对比 → 谁赚、为什么、可持续吗
        ↓
第 3 层 判断与建议：可执行的商业判断 + 口径 + 风险与局限
第 4 层 创业视角：从样本反推"活得久的公司靠什么活"，落成决策工作台
```

## 6. 交付与里程碑

- **M1 数据底座**：5 家财报接口 + 宏观源数据 → 宽表 + 数据字典（`data/`、`reports/00`）；
- **M2 宏观**：行业规模/增速/目的地/主体进出（`reports/04` + 中文图）；
- **M3 公司对比**：毛利率/销售费用率/净利率/增速/OCF，精品 vs 铺货分水岭（`reports/02` + 图）；
- **M3b 现金流深挖**：安克"有利润没现金"，追调节附表找存货/应收（`reports/03` + 图）；
- **M6 决策工作台**：把结论做成 P1-P4 交互工具（`streamlit_app/`）；
- 对外交付：13 页项目故事 PPT + 本仓库（含 docs/ 详细文档）+ 在线 Demo。

## 7. 局限（我主动写清）

- 上市公司是幸存者，不代表行业整体成功率；
- 主营构成接口地区粒度只到境外/境内，欧美细分靠年报补充；
- 公司营收含部分非跨境/全渠道业务，自下而上测算为近似下限；
- 海关统计口径与公司营收口径不可精确对应；
- 结论只到证据能到的地方，具体品类需求热度、供应商报价属私有数据。
