# B1 项目方案书：中国跨境电商 / 出海赛道分析
> 目标岗位：数据分析师 / 商业分析师 / 产品经理（数据型、策略型）
> 定位：**旗舰项目**——不是"用公开数据集跑一遍"，而是"用你真实的行业经验 + 公开财报数据，做一个别人抄不走的商业分析"。
> 数据全部来自公开合规来源（上市公司财报、海关统计、行业报告），**不涉及爬取任何平台**。

---

## 1. 一句话定位

**用 5 家中国跨境电商上市公司的公开财报数据，回答"出海这门生意到底怎么赚钱、不同打法（品牌 vs 铺货、北美 vs 欧洲 vs 东南亚、平台 vs 独立站）谁更优"，并给出可验证的商业判断。**

> 面试官视角的价值：你不是在"展示会 pandas/SQL"，而是在展示**商业分析师的核心能力——把模糊的行业问题拆成可量化的对比框架，用数据支撑判断，并诚实说明证据边界**。

## 2. 业务问题（先定义清楚，再动手）

### 核心问题
中国跨境电商卖家的盈利能力到底由什么决定？

### 拆成 4 个可量化子问题
1. **赛道**：中国跨境电商整体规模和增速还有多大？（宏观）
2. **模式**：精品品牌 vs 泛品铺货，谁的盈利质量更高、更可持续？（对比安克/致欧 vs 赛维/华凯易佰）
3. **市场**：北美 vs 欧洲 vs 东南亚，哪个市场更赚钱、竞争更友好？（对比安克 vs 致欧 vs 吉宏）
4. **渠道**：依赖亚马逊平台 vs 做独立站/DTC，渠道结构如何影响费用与利润？（平台为主 vs 吉宏社交电商/独立站）

> 每个问题都要能落到"**所以建议怎么做 + 用什么指标验证**"，不能只停在"A 比 B 高"。

## 2A. 选题动机：这个项目为什么长在你身上（面试叙事）

你的真实经历提供了三个"只有你讲得出"的观察，项目就是来验证和放大它们的：

### 观察 1：生意模式困惑——"单 SKU 赚钱，公司整体却不太赚钱了"
- 你负责新品选品和定价时会把 ROI 算进去，说明单品层面是赚钱的；但公司层听到的是"利润挺高、整体不赚钱、没以前赚了"。
- 项目切入点：把视角从单 SKU 毛利上升到公司层盈利结构——销售费用率（平台佣金+FBA+广告）、存货周转、经营现金流。
- 对应的公开数据问题：**钱到底被谁赚走了？是平台，还是模式本身？**

### 观察 2：你其实处在"品牌 vs 铺货"之外的第三种打法——长尾全品类品牌
- 我上一家公司不是 Anker 式爆款精品，也不是纯铺货测款，而是用规格矩阵（两通/三通 × 1/2"~2" × 不锈钢/黄铜/PVC）把一个细分品类做"全"，用"你想要的型号我都有"建立品牌心智。
- 给项目加一个更细的第三极：**目录式长尾品牌（assortment completeness）**。可用公开数据对比各家的 SKU 广度 vs 收入集中度 vs 毛利/费用结构，验证"做全品类"到底是不是一条好路。

### 观察 3：市场与渠道的一手体感
- **美国 NPT 螺纹 vs 欧洲 G 螺纹**：同一品类跨市场不是简单搬运，产品线几乎要重做 → 解释了"欧洲毛利高但很多卖家进不去"。
- 你们同时做 Amazon + eBay + Shopify：对平台佣金/FBA/广告与独立站自建的成本结构有真实体感 → 渠道轴你能讲出别人讲不出的细节。
- **Case Pack 亲测**：单价打 8 折 + 整箱卖，ROI 仍大幅提升 → 平台批量折扣政策与卖家策略互动的真实案例 → 是"平台抽成经济学"最好的引子。

### 面试开头模板（用真实动机，不用套话）
> "我上一份工作在一家做自有品牌出海的公司做亚马逊运营，卖阀门/管件、实验室仪器、封口机这类偏专业的产品，在售 SKU 超过 1000 个。我给新品定价前先算单件 ROI，却发现单个 SKU 都能盈利，公司整体却没以前赚钱了。我没看过公司完整账目，这只是我听到的说法，可能也和广告投放的调整有关。我怀疑利润要么被平台佣金、仓储和广告成本吃掉，要么是我们多 SKU 长尾的打法本身有问题。于是我基于 5 家跨境上市公司的公开财报做研究，把视角从单 SKU 运营上升到公司盈利结构，对比品牌爆款、纯铺货，以及像我们这样靠全品类覆盖的三种打法，再看平台依赖与独立站对利润的影响。"

## 5. 分析框架（三层漏斗）

```
第 0 层 数据底座：5 家财务数据 + 宏观数据 → 统一口径的宽表 + 数据字典
        ↓
第 1 层 宏观（行业）：赛道规模/增速 → "这个行业还值不值得进、增长来自哪"
        ↓
第 2 层 中观（公司对比，核心）：
        ├─ 规模与增长：营收、营收增速、归母净利增速
        ├─ 盈利质量：毛利率、净利率、销售费用率、经营现金流/净利
        ├─ 运营效率：存货周转、存货/营收（铺货 vs 品牌的命门）
        ├─ 结构：分地区收入占比、分品类收入占比、渠道占比
        └─ 结论：模式/市场/渠道 三维对比 → 谁赚、为什么、可持续吗
        ↓
第 3 层 判断与建议：2~3 条可执行的商业判断 + 验证口径 + 风险与局限
第 4 层（可选）创业视角：
        ├─ 赢家画像：从 5 家公司反推"活得久的公司靠什么活"（毛利/存货/现金流/渠道）
        ├─ 单位经济测算器：用平台公开费率表（佣金+FBA+广告）判断"某品类某定价能不能赚钱"
        └─ 数据边界：明确回答不了什么（供应商/货代/存活率，幸存者偏差）
```

## 6. 指标字典（每个指标：定义 / 口径 / 来源 / 注意）

| 指标 | 定义/口径 | 来源 | 注意 |
|---|---|---|---|
| 营业总收入 | 报告期营收（累计） | 财务摘要 | 半年报为 H1 累计，跨期对比要**对齐期间**（同比/环比用同期间） |
| 营收同比增速 | 同口径期间对比 | 自己算 | 注意上市年份（华凯易佰借壳/赛维上市晚，历史期少） |
| 毛利率 | (营收−营业成本)/营收 | 主营构成已给 / 自己算 | 分产品毛利率比整体更有信息量 |
| 净利率 / 归母净利率 | 净利/营收 | 财务摘要+自己算 | 区分归母 vs 含少数股东 |
| 销售费用率 | 销售费用/营收 | **需从利润表接口或年报补** | 跨境电商销售费用含平台佣金+广告，是"买量/付平台费"指标，**非常关键** |
| 研发费用率 | 研发费用/营收 | 同上 | 品牌 vs 铺货差异大 |
| 存货 / 存货周转 | 存货余额；存货/营收 | 财务摘要可能含；否则年报 | **泛品铺货的存货减值风险是核心故事点** |
| 经营现金流净额 | 报告期经营现金流 | 财务摘要 | 与净利对比看"利润含金量" |
| 境外收入占比 | 境外/营收 | 主营构成(按地区) | 目前接口到"境外/境内" |
| 分地区(北美/欧洲) | 各市场收入 | **年报 PDF 提取** | 各公司披露粒度不一，需统一口径 |
| 分品类收入占比 | 品类收入/营收 | 主营构成(按产品) | 安克: 充电/智能创新/智能影音 |
| 渠道占比(平台/独立站) | 各渠道收入 | 年报/招股书 | 吉宏以社交电商为主 |

> **实施要点**：先拉全量接口数据，检查字段覆盖；缺口（销售费用明细、地区细分、渠道）从年报 PDF 定向补充，并以年报数字抽查核对接口准确性（如安克 2025 全年营收 305.1 亿 ↔ 年报数字）。

## 10. 会被追问的问题（提前准备）

1. 数据哪来的？怎么保证准确？ → 公开财报；接口数据与年报 PDF 抽查核对；akshare 只是采集工具。
2. 为什么用"境外/境内"而不是北美/欧洲？ → 接口粒度如此；如需细分从年报补，且各公司披露口径不一——这本身是局限说明。
3. 毛利率高就代表好公司吗？ → 不一定，还要看销售费用率、存货、现金流；安克毛利 ~50% 但销售费用也高，要看净利率和 ROE。
4. 铺货型公司值不值得投/做？ → 看周转与现金流；华凯易佰/赛维的存货风险是核心观察点。
5. 你给的结论，怎么验证它是对的？ → 每条判断配套"观察指标"（如跟踪未来 2 个季度销售费用率/存货周转变化），并可和行业报告交叉验证。
6. 这个分析能迁移到别的行业吗？ → 框架通用：赛道规模 → 可比公司 → 三维对比 → 结论与验证。
7. 亚马逊为什么要给 Case Pack/批量单佣金折扣？它自己怎么赚钱？ → 亚马逊收入大头是三块：卖家佣金（referral fee，按品类约 8%~17%）、FBA 仓储配送费（按体积/重量/存放时长）、广告竞价。给整箱折扣看似少抽佣金，但换来：单票履约成本下降（整箱一次处理更省）、客单价与成交规模变大、卖家更有钱投广告/留在平台 → 平台总收费池反而更大。本质是用单笔让利换生态规模，不是零和；卖家多赚的部分，平台会通过广告、超期仓储费、流量分配部分拿回来。
8. 你们 1000+ SKU 算精品还是铺货？ → 都不是，是第三种：目录式长尾品牌——用规格矩阵把一个细分品类做全，靠"你想要的型号我都有"建立品牌心智（对比：安克爆款聚焦 vs 赛维铺货测款 vs 我上一家公司的全品类覆盖）。
9. 为什么你们欧洲只做少量？ → 阀门接口标准不同：美国用 NPT 螺纹、欧洲用 G 螺纹，同一品类跨市场要重新开模做产品线，不是简单搬仓 → 说明欧洲毛利率高但很多卖家进不去的深层原因之一是产品本地化成本。
